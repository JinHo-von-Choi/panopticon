# Panopticon

Panopticon은 소규모 사무실·연구실·개발망의 통신을 관찰하는 네트워크 보안 모니터링 도구입니다. 어떤 장치가 어떤 서비스에 연결하는지 확인하고, 포트 스캔·주소 위조·비정상 전송 등의 징후를 한 화면에서 검토할 수 있습니다.

패킷과 탐지 결과는 자체 서버에 저장합니다. 외부 위협 정보와 알림 채널, AI 분석은 선택해서 사용합니다.

## 어떻게 사용하나요?

1. **관측 위치를 정합니다.** 전체 구간을 보려면 스위치의 미러링 포트(SPAN)에 센서를 연결합니다. 일반 스위치 포트에서는 센서가 연결된 장치의 통신과 일부 브로드캐스트만 보일 수 있습니다.
2. **설치하고 관측 범위를 확인합니다.** 대시보드의 설치 점검에서 인터페이스·저장소·인증 상태를 확인합니다.
3. **사건의 근거를 검토합니다.** 출발 장치, 통신 상대, 발생 횟수, 패킷 증거와 관련 사건을 함께 봅니다.
4. **업무와 공격을 구분합니다.** 장치 소유자와 정상 업무를 확인하고, 탐지 설정을 바꿀 때는 정상·공격 샘플의 비교 결과를 검토합니다.

설치는 [설치 가이드](docs/INSTALL.md), 화면 사용은 [사용 가이드](docs/USER-GUIDE.md)에서 시작하세요.

## 주요 기능

| 기능 | 사용할 때 |
| --- | --- |
| 장치 목록과 통신 변화 | 새 장치·새 상대·평소와 다른 연결을 확인할 때 |
| 위협 탐지와 관련 사건 묶음 | 주소 위조, 스캔, 의심스러운 내부 이동·전송을 조사할 때 |
| 반복 경보 집계 | 같은 경보가 반복될 때 대표 사건과 발생 횟수를 확인할 때 |
| 패킷 증거와 검토 보존 | 사건 당시의 패킷을 확인하고 조사 기간 동안 보존할 때 |
| 업무 역할과 기대 통신 | 확인된 백업·DB 작업을 일반적인 트래픽 변화와 구분할 때 |
| 설정 제안과 비교·승인 | 변경 전후의 관측 결과를 확인한 뒤 탐지 기준을 조정할 때 |
| 알림과 운영 상태 | 알림 채널, 저장 실패, 대기열과 관측 누락을 확인할 때 |

콘솔은 한국어와 영어를 지원합니다. `Ctrl+K` 또는 `Cmd+K`로 화면을 찾고 이동할 수 있습니다.

## 설치 전에 알아둘 점

- Linux, Docker Compose 또는 Python 3.12 이상, PostgreSQL이 필요합니다. 저장 용량은 보존 기간과 관측량에 맞춰 준비하세요.
- 캡처에는 해당 인터페이스에 대한 권한이 필요합니다. 설치자가 관리할 수 있는 네트워크에서 사용하세요.
- HTTPS로 암호화된 통신의 본문을 복호화하지 않습니다. 관측하지 못한 구간의 안전 여부도 판단할 수 없습니다.
- 기본 운영 구성은 단일 센서·단일 워커입니다. 다중 워커와 고가용성 구성은 기본 지원 범위에 포함하지 않습니다.
- 자동 차단은 기본적으로 꺼져 있습니다. 실제 차단은 센서가 통제하는 트래픽 경로에만 적용됩니다. 미러링 포트에 연결된 센서의 방화벽으로 다른 장치끼리의 통신을 차단할 수는 없습니다.
- AI는 설명과 설정 후보를 제안합니다. 설정 승인과 방화벽 변경을 대신 수행하지 않습니다.
