# Panopticon

Panopticon은 소규모 사무실, 연구실, 개발망 환경에서 보안 경보를 조사하고 판정 내역을 기록하는 보안 콘솔입니다. 기존 Suricata 환경의 EVE 로그를 직접 읽어 들여 쏟아지는 반복 경보를 묶어 내며, 해당 장치의 역할이나 업무 일정, 통신 근거를 한 화면에서 맞춰 봅니다.

정상 백업 전송인지 미확인 대상과의 통신인지 확인하고 근거를 남깁니다. 조사 기록은 자체 서버 PostgreSQL에 보관합니다. 외부 알림과 AI 분석은 필요할 때 켜는 선택 사항입니다.

## 어떻게 사용하나요?

1. **Suricata 로그를 연결합니다.** 읽기 권한이 있는 `eve.json` 경로를 지정해 설치하며 기본 구성에는 별도 패킷 캡처 권한이 필요 없습니다.
2. **입력과 보존 상태를 확인합니다.** 운영 화면에서 수집 연결 상태, 저장 실패 건수, 누락 가능성, 잔여 보존 용량을 점검합니다.
3. **우선 처리할 사건을 조사합니다.** 중복 경보의 대표 사건을 열어 과거 이력, 출발 장치 정보, 상대 호스트와 원본 로그를 대조합니다.
4. **업무 판정과 인계를 남깁니다.** 담당자를 배정하고 정상 업무 근거, 적용 범위, 유효 기한을 입력하며 상황이 바뀌면 다시 검토합니다.

자세한 설치 방법은 [설치 가이드](docs/INSTALL.md)를, 화면 조작법은 [사용 가이드](docs/USER-GUIDE.md)를 참고하십시오.

## 무엇을 할 수 있나요?

- **반복 경보 조사:** 전체 발생 횟수와 개별 원본을 분리해 파악하고 과거 유사 사건과 비교합니다.
- **업무 맥락 확인:** 장치 역할, 담당자, 평소 기대 통신, 작업 일정을 등록해 정상 업무 여부를 가리는 판단 근거로 활용합니다.
- **판정과 협업:** 처리 담당자와 상태, 인계 메모, 최종 판정 이력을 저장하며 관리자·분석가·조회자 권한을 명확히 구분합니다.
- **증거 보존:** 원본 경보와 조사 내역을 열람합니다. 직접 캡처 방식을 쓸 때는 저장된 패킷 데이터까지 바로 확인합니다.
- **탐지 설정 검토:** 지원 센서 환경에서 규칙 변경 후보를 정상·공격 샘플에 교차 검증한 후 관리자 승인을 거쳐 반영합니다.

콘솔은 한국어와 영어를 지원합니다. `Ctrl+K`나 `Cmd+K` 단축키로 원하는 화면을 즉시 찾아갑니다.

## 설치 전에 알아둘 점

- Linux, Docker Compose 또는 Python 3.12 이상, PostgreSQL 환경이 필요합니다. 저장 공간은 설정한 보존 기간과 네트워크 트래픽 관측량에 맞춰 넉넉히 확보하십시오.
- 기본 EVE 연동은 Suricata가 남긴 경보만 다룹니다. 로그에 기록되지 않은 패킷 흐름이나 장치 소유 관계를 자의적으로 추정해 증거를 꾸며내지 않습니다.
- 원시 패킷을 직접 캡처하려면 별도 센서 패키지를 올리고 SPAN 포트나 TAP 장비, 시스템 캡처 권한을 갖춰야 합니다. 반면 웹 콘솔 자체는 패킷 캡처 권한 없이 안전하게 구동됩니다. 상세 절차는 [직접 캡처 설치](docs/INSTALL.md#직접-패킷을-캡처하기)를 참고하십시오.
- 암호화된 HTTPS 통신 본문을 임의로 복호화하지 않으며 장비가 직접 보지 못한 구간의 안전을 보장하지도 않습니다. 장비가 감당하는 처리 성능은 유입 트래픽, 적용한 룰셋, 물리 서버 사양에 따라 차이가 납니다.
- 기본 직접 캡처 구성은 단일 센서와 단일 워커 프로세스 기준입니다. 다중 워커 분산 처리나 고가용성(HA) 구성은 기본 지원 범위에서 제외됩니다.
- 본 패키지는 읽기 전용 분석 도구입니다. 콘솔에서 업무 판정을 내렸다고 해서 탐지 예외 규칙이 자동 생성되거나 방화벽 정책이 바뀌지 않으며, AI가 관리자의 설정 승인 작업을 대신 처리하지도 않습니다.
