# 기여 기준

이 문서는 기능을 추가하거나 변경할 때 확인할 제품 동작과 검증 기준입니다. 개발 환경과 명령은 [개발 가이드](DEVELOPMENT.md)를 참고하세요.

## 탐지와 관측

관측 범위와 입력 누락을 함께 표시합니다. 경보가 없다는 이유로 관측 구간이 안전하다고 설명하지 않습니다. 누락률은 같은 단계와 시간의 수신 수를 기준으로 계산하고, 앱·커널·네트워크 장비의 누락을 합치지 않습니다.

정상 업무를 완화할 때는 장치 소유 관계, 상대, 서비스, 시간과 전송량을 확인합니다. 확인되지 않거나 만료된 조건에는 적용하지 않습니다. 공격 입력으로 정상 기준선이 학습되지 않도록 관련 상태와 회귀 시험을 확인합니다.

## 변경과 승인

AI와 분석 역할은 설명과 제안을 작성합니다. 설정 쓰기와 승인에는 관리자 권한이 필요합니다. API의 권한 검사와 실제 변경 경로가 일치해야 합니다.

설정 후보에는 기준값과 비교 결과를 연결합니다. 현재 설정이 바뀌었거나 공격 관측을 잃는 후보는 적용하지 않습니다. 파일 저장이나 엔진 재생성이 실패하면 이전 설정과 엔진 상태를 유지하고 실패를 반환합니다.

## 저장과 외부 효과

DB의 확정 저장, 패킷 파일 생성, 알림 전달과 OS 차단은 각각 결과를 확인합니다. 저장·전달 응답을 받지 못한 상태를 성공으로 처리하지 않습니다.

재시도 가능한 저장은 식별자로 중복을 막습니다. 원격 전달이나 방화벽 조치는 응답 유실 시 중복 실행의 영향을 고려해야 합니다. 대기열·메모리·파일·시간에는 상한을 둡니다.

## 방화벽과 권한

대상과 관리 경로의 영향, 만료 시간과 복구 방법을 확인합니다. 실제 트래픽 경로를 통제할 수 있는 위치에서만 차단 효과를 검증합니다. 미러링 센서의 로컬 방화벽을 네트워크 전체 차단으로 설명하지 않습니다.

외부 입력을 셸 명령으로 실행하지 않습니다. 지원되지 않는 백엔드나 권한 구성을 지원 기능으로 표시하지 않습니다.

## UI와 문서

요청 중, 적용 완료, 실패와 확인 불가 상태를 구분합니다. 화면 갱신이 필터·선택·초점을 불필요하게 바꾸지 않도록 확인합니다. 중요 상태는 색뿐 아니라 문구로 설명합니다.

문서는 독자가 수행할 작업과 확인할 결과를 중심으로 씁니다. 개인 경로, 비공개 접속 정보, 개발 일지와 실행 로그를 사용 가이드에 넣지 않습니다. 기능 설명은 현재 구현과 일치해야 합니다.

## 검증

변경과 관련된 시험, 마이그레이션과 출시 검사를 수행합니다. 건너뛴 시험과 실제 장비가 필요한 항목을 구분해 기록합니다. 특정 장비의 짧은 합성 실험을 일반적인 성능 보증으로 사용하지 않습니다.
