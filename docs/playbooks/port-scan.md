# 포트 스캔 의심 사건 조사

포트 스캔은 한 장치가 여러 서비스 포트에 접근하는 활동입니다. 공격 준비뿐 아니라 승인된 취약점 검사나 자산 탐색도 같은 형태를 보일 수 있습니다.

## 확인 순서

1. 사건 상세에서 출발 장치, 상대, 접근 포트와 발생 시각을 확인합니다.
2. 장치 목록에서 소유자와 설치 목적을 확인합니다. IP만으로 소유자를 확정하지 마세요.
3. 취약점 검사·운영 점검 일정과 해당 활동이 일치하는지 담당자에게 확인합니다.
4. 목적지와 포트 범위, 반복 빈도, 관련 내부 이동·인증 실패 사건을 확인합니다.

승인된 검사라면 담당자와 시간·대상 범위를 기록합니다. 탐지 기준을 조정해야 한다면 정상·공격 샘플을 비교하고 제안 승인 절차를 사용합니다. 출발 IP 전체를 무조건 허용하면 다른 활동도 조사에서 빠질 수 있습니다.

승인되지 않은 활동이면 네트워크 담당자와 장치 격리나 접근 제한을 검토합니다. 실제 경로와 업무 영향, 복구 방법을 확인한 뒤 조치하고 동일 출발지·대상에서 다시 발생하는지 관찰합니다.

## 종료 확인

활동의 원인, 확인한 범위, 조치와 정상 서비스 영향을 기록합니다. 관련 증거와 승인 결과를 보관하세요.
