# ARP 위조 의심 사건 조사

ARP 위조 경보는 IP와 MAC의 연결 관계가 예상과 달라졌을 때 조사할 신호입니다. 장치 교체, 주소 이동과 이중화 전환도 원인이 될 수 있습니다.

## 확인 순서

1. 사건 상세에서 변경 전후 IP/MAC, 시각과 패킷 증거를 확인합니다.
2. 장치 목록과 DHCP·네트워크 관리 기록에서 현재 소유자를 확인합니다.
3. 같은 시점의 장치 교체나 게이트웨이 전환 작업이 있었는지 담당자에게 확인합니다.
4. 게이트웨이 주소를 다른 장치가 주장하거나 예상하지 못한 MAC이 반복해서 나타나는지 확인합니다.
5. 관련 통신 변화와 다른 경보를 함께 조사합니다.

정상 변경으로 확인됐다면 장치 소유 관계와 근거를 갱신합니다. 조사 없이 IP를 넓게 허용 목록에 넣지 마세요.

위조가 의심되면 네트워크 담당자에게 해당 장치와 스위치 포트의 격리를 요청합니다. 관리자 접속 경로와 업무 영향을 확인하고 조치를 기록합니다. SPAN 센서의 로컬 방화벽만으로 다른 장치 사이의 위조 통신을 막을 수는 없습니다.

## 종료 확인

문제가 된 주소 관계가 더 이상 나타나지 않는지, 정상 장치의 통신이 복원됐는지 확인합니다. 조사 중인 증거는 검토 보존하고 정상 변경 또는 조치 결과를 기록합니다.
