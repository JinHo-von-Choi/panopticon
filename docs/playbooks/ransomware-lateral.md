# 의심스러운 내부 이동 조사

SMB·RDP 등 내부 서비스에 대한 비정상 접근은 감염 장치의 확산이나 계정 악용을 조사할 신호입니다. 경보만으로 랜섬웨어 감염이 확정되지는 않습니다.

## 확인 순서

1. 사건 상세에서 출발 장치, 서비스 포트, 상대 장치와 발생 시각을 확인합니다.
2. 같은 출발지의 스캔·대량 전송·반복 접근 등 관련 사건을 확인합니다.
3. 백업·배포·원격 관리 작업이 있었는지 담당자에게 확인합니다.
4. 서버의 로그인 기록, 엔드포인트 보안 경보, 파일 변경 등 별도 근거를 확보합니다.

공격이 의심되면 조직의 사고 대응 담당자에게 알리고 출발 장치의 네트워크 격리를 검토합니다. 공유 저장소와 관리자 계정의 접근 범위를 확인하고, 조사 중인 자료와 패킷 증거를 보존합니다.

Panopticon의 관측만으로 파일 암호화나 악성코드 실행을 확인할 수는 없습니다. 엔드포인트 조사 결과와 연결해 판단하세요. 업무와 관리 접속의 영향을 확인하지 않은 광범위 차단은 피합니다.

## 종료 확인

원인 장치와 계정, 조사 범위, 격리·복구 조치와 정상 업무 복원을 기록합니다. 재발 관측과 엔드포인트 점검을 함께 수행하세요.
